# 隐私和安全

Dayframe 是单用户本地服务。默认 Compose 只将管理界面绑定 `127.0.0.1:8765`，Windows 桌面版使用系统分配的 `127.0.0.1` 端口；都不是面向公网的多用户网站。不要改成公网绑定或通过隧道共享管理界面。浏览器内的摄像头在用户启动拍摄后才使用，退出流程应关闭流；城市由用户填写，不默认精准定位。

核心页面不请求远程照片、AI、地图瓦片、字体或遥测。构建和镜像下载需要网络，运行核心归档不需要网络。HTTP access log 默认关闭以避免记录文件与配对信息。

文件内容通过图像解码验证，原始字节单独保存。路径解析必须留在授权目录内，拒绝越界和符号链接逃逸。HTML 导出转义用户内容；备份和恢复校验完整清单，恢复不覆盖旧目录。

手机配对在独立端口，默认关闭，有短期随机凭据、时间限制和上传数量/大小限制。手机只有上传能力，不能访问管理 API 或原图。上传后在电脑端明确批准才加入归档。只在可信私有 Wi-Fi 使用：HTTP 的局域网传输未加密；不能称为端到端加密。

未来信件的时间锁只在界面/API 展示层生效；本地 JSON 明文可读。这不适合用作加密保险箱。原图导出可能保留 EXIF（包括设备和 GPS），分享前自行检查元数据。

Docker 运行时使用 UID10001 非 root、丢弃 capabilities、禁止提权。FFmpeg 是独立的 Debian 系统程序，镜像包含其许可证和系统发行说明；它的编解码器许可、专利和再分发条件仍应按使用地区审查。应用不把编码器可用性当作数据保存条件。

若要远程访问或多人使用，应另行设计身份认证、TLS 和访问隔离，而不是直接开放本地端口。

## Windows 桌面边界

Tauri 通过 stdin 把每次启动随机生成的凭据交给受管 sidecar，凭据不放入进程命令行。后端就绪后的一次性启动入口设置 HttpOnly、SameSite Cookie；桌面管理接口还需该 Cookie，继续验证 Host 和 Origin。真实前端与 API 同源，未设置通配 CORS。HTTP access log 关闭，避免启动 URL 或配对信息进入访问日志。

桌面服务只有 IPv4 环回管理监听。单实例和归档独占锁防止重复写入；正常关闭会请求后端退出，Windows Job Object 管理崩溃时的后代清理。这些措施不隔离本机其他账户权限或已被攻陷的操作系统；拥有归档访问权限的本机程序仍可读取原图和明文 JSON。

路径设置保存在 `%LOCALAPPDATA%\DayFrame\Settings\desktop.json`，日志在同级 `Logs`。归档、备份和设置不写入安装或 PyInstaller 解包目录。路径验证拒绝无写权限、相互重叠、链接/连接点及受保护运行目录；修改保存后重启生效，不自动迁移、覆盖或删除档案。升级、卸载前仍需独立校验备份。

手机上传仅由用户主动开启，不自动设置防火墙或登录启动。测试使用的 `DAYFRAME_DATA_HOME`、`DAYFRAME_SMOKE_STATUS` 和 WebView2 调试入口只用于隔离验收；不要对个人归档启用测试调试配置，普通运行不启用远程调试。

Windows 安装器目前未代码签名，来源与摘要核对见 [WINDOWS_INSTALL.md](WINDOWS_INSTALL.md)。桌面 FFmpeg 来自 imageio-ffmpeg 分发，实际二进制许可与材料见 [THIRD_PARTY.md](THIRD_PARTY.md)；Docker 的 Debian FFmpeg 分发方式保持独立。
